# Web Rules

- Frontend dùng HTML, Tailwind CSS và vanilla JavaScript theo PRD.
- Giữ navigation rõ ràng: Giới thiệu, HAL, Register, So sánh, Test.
- Code block phải có nút copy hoạt động và thông báo kết quả dễ hiểu.
- Không phụ thuộc build step nếu mở trực tiếp `index.html` là đủ.
- Kiểm tra responsive ở mobile và desktop.
- Nội dung trong web phải bám các tài liệu `PRD.md`, `docs/reference-register.md` và source firmware tham chiếu.
