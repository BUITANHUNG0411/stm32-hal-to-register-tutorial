# Markdown Rules

- Mỗi file có một mục tiêu chính và một tiêu đề H1.
- Dùng heading theo thứ tự H1 → H2 → H3; không nhảy cấp.
- Ưu tiên bảng cho mapping, checklist cho acceptance criteria và code fence có language tag cho code.
- Dùng đường dẫn tương đối trong nội bộ project.
- Không nhúng nội dung dài vào `CLAUDE.md`; chuyển sang `docs/` hoặc path-scoped rule.
- Khi tài liệu thay đổi hành vi hoặc scope, cập nhật `PRD.md` trước.
